סקירה כללית

אלגוריתם PDN מחשב קוד אישיות ייחודי על בסיס שאלון בן 67 שאלות. הקוד מורכב מתכונה דומיננטית (אות) + סוג אנרגיה (מספר), לדוגמה: A7, P10, T4.

החישוב מתבצע ב-5 שלבים, כאשר כל שלב מוסיף נקודות לתכונות ולאנרגיות בהתאם לתשובות המשתמש.

שלב A: תכונות → שלב B: אנרגיה → שלב C: חיזוק → שלב D: שילובים → שלב E: סיום → 🎯 קוד PDN

שלב A — חישוב תכונות ראשי

A
שאלות 1-26 — בחירה בינארית

כל שאלה מציגה שתי אפשרויות, כל אחת מייצגת זוג תכונות. בחירת אפשרות מוסיפה +1 לכל אחת משתי התכונות בזוג.

קודי ניקוד:

קודתכונות שמקבלות +1דוגמה לשאלה
APA +1, P +1"פחות מאורגן", "ספונטני", "מוסח בקלות"
ETE +1, T +1"מאורגן", "מחושב", "מרוכז"
AEA +1, E +1"מביע דעתי", "יוזם", "לוקח פיקוד"
TPT +1, P +1"מקשיב", "נסוג", "מצטרף"
if answer == 'AP': scores['A'] += 1; scores['P'] += 1 if answer == 'ET': scores['E'] += 1; scores['T'] += 1 if answer == 'AE': scores['A'] += 1; scores['E'] += 1 if answer == 'TP': scores['T'] += 1; scores['P'] += 1
תוצאה: בסוף שלב A, לכל תכונה ניקוד מצטבר. התכונה עם הניקוד הגבוה ביותר היא הדומיננטית הראשונית.

שלב B — חישוב סוג אנרגיה

B
שאלות 27-37 — דירוג 3 אפשרויות

11 שאלות דירוג. כל שאלה מציגה 3 תיאורי אנרגיה (D, S, F). המשתמש מדרג מ-1 (הכי מתאים) ל-3 (הכי פחות מתאים).

שיטת ניקוד:

דירוגניקוד
מקום 1 (הכי מתאים)+3 נקודות
מקום 2+2 נקודות
מקום 3 (הכי פחות)+1 נקודה
for each ranking question (27-37): for energy, rank in ranking.items(): if rank == 1: energy_scores[energy] += 3 if rank == 2: energy_scores[energy] += 2 if rank == 3: energy_scores[energy] += 1
טווח ניקוד: כל אנרגיה יכולה לצבור 11-33 נקודות (11 שאלות × 1-3 נקודות). האנרגיה עם הניקוד הגבוה ביותר היא הדומיננטית.

שלב C — חיזוק וזיהוי עדין

C
שאלות 38-42 — סקאלה בין שני קטבים

5 שאלות סקאלה. כל שאלה מציגה שני קטבים (למשל A מול T, או P מול E). המשתמש בוחר נקודה על סקאלה של 7 מדרגות.

שיטת ניקוד:

הסקאלה ממופה לניקוד זוגי: [12,0], [10,2], [8,4], [6,6], [4,8], [2,10], [0,12]

ההפרש בין הניקודים קובע: הצד עם הניקוד הגבוה יותר מקבל +1 לתכונה שלו.

for question in 38-42: trait1, trait2 = question.options value1, value2 = ranking[trait1], ranking[trait2] difference = value1 - value2 if difference > 0: scores[trait1] += 1 if difference < 0: scores[trait2] += 1

D

14 שאלות סקאלה. כל שאלה מציגה שילוב של שתי תכונות (למשל TP מול AE, או AP מול TE). הצד המנצח מוסיף +1 לכל אחת משתי התכונות בשילוב.

קודי שילוב:

שילובאם מנצח, מוסיף +1 ל:
TPT +1, P +1
AEA +1, E +1
APA +1, P +1
TET +1, E +1
for question in 43-56: combo1, combo2 = question.options # e.g., "TP", "AE" value1, value2 = ranking[combo1], ranking[combo2] if value1 > value2: scores[combo1[0]] += 1 # e.g., T += 1 scores[combo1[1]] += 1 # e.g., P += 1 elif value2 > value1: scores[combo2[0]] += 1 scores[combo2[1]] += 1

שלב E — חיזוק חזק לתכונה דומיננטית

E
שאלות 57-61 — דירוג 4 תיאורים (משקל גבוה)

4-5 שאלות דירוג עם משקל גבוה מאוד. כל שאלה מציגה 4 תיאורי אישיות (אחד לכל תכונה A, T, P, E). המשתמש מדרג מ-1 ל-4.

שיטת ניקוד (משקל כבד):

דירוגניקודהסבר
מקום 1 (הכי מתאים)+8 נקודותמשקל כבד מאוד — מטרה לשבור שוויון
מקום 2+4 נקודות
מקום 3+2 נקודות
מקום 4 (הכי פחות)0 נקודות
for question in 57-61: for trait, rank in ranking.items(): if rank == 1: scores[trait] += 8 if rank == 2: scores[trait] += 4 if rank == 3: scores[trait] += 2 if rank == 4: scores[trait] += 0
חשוב: שלב זה מהווה את המשקל הגבוה ביותר באלגוריתם. 4 שאלות × 8 נקודות = עד 32 נקודות לתכונה. המטרה היא לשבור שוויון ולחדד את התכונה הדומיננטית.

ציון ביטחון (Confidence Score)

ציון הביטחון (0-100%) מודד כמה "ברורה" האבחנה — כלומר, עד כמה התכונה והאנרגיה הדומיננטיות בולטות ביחס לשאר.

חישוב:

הציון מחולק ל-2 חלקים שווים:

  • ביטחון תכונה (0-50 נק׳): הפער בין התכונה הגבוהה ביותר לשנייה, כאחוז מסך הנקודות
  • ביטחון אנרגיה (0-50 נק׳): הפער בין האנרגיה הגבוהה ביותר לשנייה, כאחוז מסך הנקודות
trait_gap = highest_trait - second_highest_trait trait_dominance = (trait_gap / total_trait_scores) × 100 trait_confidence = min(50, trait_dominance × 2.5) energy_gap = highest_energy - second_highest_energy energy_dominance = (energy_gap / total_energy_scores) × 100 energy_confidence = min(50, energy_dominance × 2.5) confidence_score = trait_confidence + energy_confidence // 0-100

פרשנות:

טווחצבעמשמעות
80-100%🟢 ירוקאבחנה ברורה מאוד — תכונה/אנרגיה בולטת
60-79%🟡 צהובביטחון בינוני — יש הפרש אך לא דרמטי
0-59%🔴 אדוםאבחנה לא חד-משמעית — ניקודים קרובים

דרישת אימות אנושי

המערכת מסמנת מקרים שדורשים אימות אנושי כאשר:

הכלל: אם הפער בין התכונה הגבוהה ביותר לשנייה בגובהה הוא 2 נקודות או פחות — נדרש אימות.
gap = highest_trait_score - second_highest_trait_score needs_verification = (gap <= 2)

במקרים אלו, התוצאה יכולה להשתנות בקלות עם תשובה אחת שונה, ולכן מומלץ שאדם מקצועי יבדוק את הפרופיל.
